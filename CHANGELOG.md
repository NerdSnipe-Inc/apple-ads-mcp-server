# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and the project uses [SemVer](https://semver.org/).

## [1.0.0] - 2026-10-10

### Added
- Initial release: 99 tools, one per operation of `@apple/apple-ads-platform` 1.109.0 (Apple Ads Platform API v1), covering 22 groups.
- Meta tools: `apple_ads_request` (escape hatch), `apple_ads_list_operations`, `apple_ads_server_status`.
- Key-based OAuth (ES256 client secret generated by the SDK), token caching, refresh-and-retry on 401, Retry-After aware backoff on 429/5xx.
- Per-call `adAccountId` context override plus `APPLE_ADS_AD_ACCOUNT_ID` / `APPLE_ADS_ORG_ID` defaults.
- Safety switches: `APPLE_ADS_READ_ONLY`, `APPLE_ADS_ENABLED_GROUPS`, `APPLE_ADS_DISABLED_GROUPS`.
- Generator (`scripts/generate.mjs`) with a drift gate, `docs/COVERAGE.md` manifest and generated coverage test.
- `scripts/install-global.sh` for Claude Code and Claude Desktop.
